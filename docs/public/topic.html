Accesibilidad Web

Me interesa la creación de interfaces que todas las personas puedan usar sin importar sus capacidades físicas, sensoriales o cognitivas.

¿Por qué importa?

La web es un servicio público global. Cuando mejoramos la accesibilidad, logramos una experiencia más clara para todos, reducimos barreras y cumplimos estándares como las WCAG.

  • Garantiza inclusión digital.
  • Mejora la usabilidad y la navegación.
  • Evita problemas legales y reputacionales.

Buenas prácticas básicas

  • Contrastes adecuados entre texto y fondo.
  • Estructura semántica con encabezados claros.
  • Textos alternativos para imágenes.
  • Formularios con etiquetas visibles.
  • Navegación accesible con teclado.

Ruta de aprendizaje

1. Fundamentos

Comprender la diversidad de usuarios, leer la introducción a WCAG y conocer las pautas ARIA.

2. Práctica guiada

Auditar sitios existentes con herramientas como Lighthouse y WAVE.

3. Mejora continua

Construir componentes accesibles, compartir pruebas con usuarios reales y documentar aprendizajes.
