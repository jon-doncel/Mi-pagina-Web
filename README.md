# Documento Detallado de Diseno (DDD)

# Descripcion del trabajo
Este proyecto es un sitio web estatico creado con HTML y CSS. Incluye una pagina principal y varias secciones publicas con informacion sobre mi, mi carrera academica y enlaces a sitios de compañeros.

# Estructura del proyecto
- `docs/index.html`: pagina principal.
- `docs/public/`: paginas secundarias (`about.html`, `topic.html`, `net.html`, `contact.html`, `degree.html`, `fii.html`).
- `docs/css/`: hoja de estilos compartida (`styles.css`).
- `docs/images/`: carpeta en la que se almacenen las imágenes.
- Archivos raiz: `README.md`.

# Uso
No hay backend ni scripts para enviar formularios; todo es interfaz.

# Problemas durante el desarrollo
- Coordinacion de estilos entre paginas para mantener consistencia visual.
- Ajustes de posición de los elementos para que la navegacion sea clara en todas las secciones.

# Conclusiones
El proyecto cumple con el objetivo de presentar informacion personal y academica en un sitio estatico sencillo. La página web unicamente dispone de front-end. Las funcionalidades como contactar con el creador de la página están desactivadas. No es una página web con elementos gráficos muy llamativos, pero cumple con su función

# Posibles mejoras

- Agregar una seccion de proyectos o portafolio.
